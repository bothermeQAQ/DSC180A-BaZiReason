# Your own questions (optional)

Put questions you wrote yourself in `questions.txt`, one per line:

```
年柱 月柱 日柱 时柱<TAB>male|female<TAB>question
```

Example: `乙亥 甲申 丙戌 癸巳	male	我这个八字的空亡在哪？`

Phase 6 ran without this file; if it is added later, `scripts/phase6/` can label the questions whose intent the rule code can decide, and they are reported as their own part.
