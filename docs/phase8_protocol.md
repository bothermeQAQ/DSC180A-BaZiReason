# Phase 8 protocol, November 22, 2026

The budget runs from 01:12 to 11:12 Pacific on November 22. Stop model work by 10:17 Pacific and reserve the last 55 minutes for verification and reporting. Stop once the listed runs and evaluations finish. Estimate 6–8 hours including design, data checks, contingencies and reporting.

## Hypothesis and intervention

On the Phase 7 development panel, the two graph-trained models wrote the correct intermediate branch on every failed primary question. On life-stage mistakes both reported the correct starting branch and direction. On Ten-God mistakes both reported the correct main hidden stem. This motivates isolating the downstream day-stem lookup. The training materials must never use the 12 Phase 7 reserved combinations. Select the conventional worked-answer adapter G as the parent because it transferred well across unaided wording changes. Include T as an existing contender because it won the old primary and rule-context comparisons.

Fit A and B from the same G endpoint. A practices isolated life-stage and Ten-God questions with balanced operands. B practices alternative single-step rules on matched charts and branch inputs. Both see the same common calendar, rule and worked graph replay. Use one shared seed and a fixed final checkpoint. Target 1.5 million sequence tokens each. Match rows and optimizer updates exactly and total, supervised and padded tokens within 3%. Freeze training and evaluation independently before eliciting any transfer replies. No model output informs item selection or prompt edits.

## Evaluation and decision

The primary outcome is family-macro exact-answer accuracy under independently authored Chinese wording, on 20 fresh charts per previously reserved directed rule family (12 families). “Independent” refers to a separate authoring agent isolated from intervention wording, with a shared BaZi vocabulary. Use ordinary chart draws without filtering on outcomes. Pair models on prompts. Pair familiar and new wording on each chart. Collect changed-source questions and isolated consumer probes for the four targeted families. Other outcomes include familiar rules and calendar accuracy on fresh historical-style panels, and Phase 7 development scores for comparison with the prior study. Evaluate G, T, A and B on new transfer and retention panels, U8 on fresh retention, and A/B on the old development panel. No repeated seed or post-result tuning.

Use one greedy model response with the historical system prompt and token limits. Keep raw outputs, ID, condition, hashes and score. Use the original typed JSON scorer and historical retention scorers. The main causal contrast is A minus B. Also require improvement over G so deterioration of the control cannot create an apparent win. Report chart-paired and family-resampled 95% uncertainty, and the targeted and other families separately. Predeclare a positive screen as an A−B advantage of at least 4 percentage points, paired chart interval excluding zero, a positive A−G primary change, and retention point losses versus both G and U8 no greater than 1.5 familiar-rule points or 2 calendar points. Interpret family resampling and one-seed uncertainty separately. Rank all four models by the primary score, show the raw leader even if retention fails, and distinguish pilot performance from a recommendation to replace a model. No second experiment or deployment follows this decision.
